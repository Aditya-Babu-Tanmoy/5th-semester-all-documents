## 📖 About This Repository

Welcome to the **5th Semester Academic Resource Collection**!

This repository organizes academic resources for Computer Science and Engineering students in one convenient location.

### 🎯 Objectives

- Organize semester-wise educational materials.
- Make subject-wise resources easy to locate.
- Support examination preparation and revision.
- Preserve lecture notes and academic references.
- Provide a useful reference for fellow CSE students.

## 🚀 How to Use

### Option 1: Browse Online

1. Open this repository.
2. Select the `5th Semester` folder.
3. Choose your subject.
4. Open the desired document.

### Option 2: Clone the Repository

```bash
git clone https://github.com/Aditya-Babu-Tanmoy/5th-semester-all-documents.git
```

Git LFS is recommended to download the full ZIP archive.

```bash
git lfs install
git lfs pull
```

### Option 3: Download the Repository

1. Click the green **Code** button.
2. Select **Download ZIP**.
3. Extract the downloaded archive.
4. Browse the subject folders.

**Important:** GitHub's regular Download ZIP option may not include the full contents of Git LFS files. Use Git LFS to retrieve the original large archive reliably.
